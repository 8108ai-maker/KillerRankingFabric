# 0.17.0 도트 칼날 텍스처

기본 내장 image_gen 도구로 생성했습니다. 투명 배경을 유지하면서 외곽 여백을 자르고 최근접 축소로 게임용 크기에 맞췄습니다. 원본은 프로젝트 작업 폴더의 `work/weapon-art`에 보존했습니다.

게임이 사용하는 최종 파일:

- `src/main/resources/assets/killerranking/textures/item/gossi_knife_blade.png` — 16×64, 나이프 날
- `src/main/resources/assets/killerranking/textures/item/eunbal_hatchet_head.png` — 32×32, 도끼날

두 텍스처 모두 얇은 앞·뒷면에만 표시합니다. 투명 부분에 입체 큐브를 채우지 않습니다. 검은 손잡이·감은 띠·금속 고리는 입체 모델입니다.
