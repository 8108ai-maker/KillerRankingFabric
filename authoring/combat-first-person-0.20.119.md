# 1인칭 공격·패리 연출

참고: [Essence of PARRY](https://www.youtube.com/watch?v=9NPbOl0LGds). 브라우저에서 15초의 검 대기·방어, 25.2초의 전방 타격, 134.6초의 짧은 흰 섬광과 134.9~135.2초의 십자 불꽃을 확인했다. 영상의 판정 시간·장비 효과는 도입하지 않았다.

일반 공격은 기존 피해 박자와 손목 채널을 보존하고, `FirstPersonCombatRig`에서 양쪽 어깨·팔 회전·실제 손바닥·무기를 같은 쿼터니언 프레임에 넣는다. 준비와 타격 후 반동은 이 프레임 전체가 움직인다. 손목을 따로 돌리거나 팔 각도의 Euler 성분을 각각 줄이지 않는다. 카메라용 몸통 기울임은 제거하고 기존 떡발·룩의 주먹 크기는 유지한다. 다른 무기의 과거 공격용 팔 늘리기는 1인칭에서 제거한다.

폰 6의 패리·반대편 패리·자동 패리·잔상 패리와 대기 자세는 새 프레임에서 제외한다. 기존 JSON과 1인칭 보정을 그대로 사용한다. 능사 발도술의 별도 카메라 프레임, 완전 발검, 2초 유지, 납검 동작도 유지한다.

패리 준비와 성공은 별개의 이벤트다. 기존 준비 패킷은 방어 모션만 시작한다. 실제 성공 시 새 `ParryImpactPayload`가 접촉 지점에 흰 십자 불꽃·짧게 뻗는 작은 불꽃을 만든다. 본인에게만 2틱의 연한 화면 섬광을 더하며 세계가 바뀌면 잔여 이펙트를 지운다. 피해·보호 시간·쿨타임 환급·자동 패리의 밀쳐내기 규칙은 바꾸지 않는다.

별도 촬영 소스는 `work/combat-view-smoke-src`, 실행 설정은 `work/combat-view-smoke.init.gradle`에 있으며 생산 JAR에는 포함하지 않는다.
