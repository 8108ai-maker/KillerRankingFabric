# 일반 패링 0.20.125

사용자의 최신 요청에 따라 0.20.124의 연속적인 측면 흘리기를 세 박자로 변경했다.

1. 손을 들어 올린다.
2. 옆으로 살짝 틀며 준비 자세를 짧게 유지한다.
3. 팔이 끊기듯 옆 위로 확 올라가 흘린다.

주손의 급격한 전환은 10→11프레임, 반대팔은 8→9프레임이다. 60fps로 작성하여 각각 약 16.7ms의 전환이며 이 구간에 느린 완화를 넣지 않는다. 준비와 복귀는 별도 경로다. 양팔의 어깨 좌표와 기존 팔·아이템 비율을 유지한다. 카타나 전용 모션은 수정하지 않는다.

실제 검증 촬영은 1920×1080, 30fps이므로 이 전환이 매 프레임으로 관찰될 수는 없다. 게임 장면에서 준비 자세 이후 팔이 옆 위로 빠르게 바뀌는지 확인한다. 화면이나 시뮬레이션을 정지시키지 않는다.
