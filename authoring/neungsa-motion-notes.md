# 능사 카타나 0.20.96

사용자 참고 영상: https://www.youtube.com/watch?v=KgHnUI0L714

브라우저에서 Yamato & Capricorn 영상의 무기 전시, 21~26초의 카타나 베기, 34초의 준비 장면, 50초의 다중 참격, 1분 7초의 원거리 효과 화면을 확인했습니다. 길고 읽기 쉬운 도트 날, 넓은 베기 궤적, 밝은 중심선과 짧게 남는 잔상을 이번 능사 연출에 참고했습니다. 영상의 무기 능력과 수치를 그대로 가져오는 작업은 아닙니다.

능사의 기존 참고 사진과 사용자 지정은 유지합니다. 검은 직선 날·검은 손잡이·금색 작은 장식, 옆 허리춤 검집에서 잡고 있는 대기 자세, 한손 베기, 보라색 도트 참격입니다. 카메라에서 비스듬히 보이는 각도를 검 모델의 비틀림으로 만들지 않습니다. 팔과 무기를 키우지 않습니다.

이번 리그는 실제로 렌더링되는 손의 위치가 손잡이 기준점입니다. 손잡이 기준점은 모델 좌표 (8, 8, 8)이며, 손목 회전만 그 기준점을 중심으로 적용합니다. 별도의 무기 위치 키를 팔 위치와 각각 보간하지 않습니다. 준비·타격·복귀 중에도 손과 검은 같은 기준점으로 움직입니다.

검을 뽑아 한손으로 좌우 베기와 내려베기를 하고, 허리·몸통·발은 짧게 따라 움직입니다. 머리 채널은 고정하지 않습니다. 반대손은 허리의 검집에 남습니다. 원거리 참격은 실제 서버 공격 시점에 한 번 발생하며, 기본 피해 4·사거리 12m입니다. 벽 충돌과 피해 판정은 서버가 처리합니다.

`neungsa_katana.bbmodel`, `neungsa_katana_sheathed.bbmodel`, `neungsa_katana_saya.bbmodel`과 `exports`의 Java 아이템 내보내기는 실제 Blockbench에서 갱신했습니다. 효과 텍스처는 새로 생성한 보라색 8프레임 원본을 확인한 뒤 256×512 도트 아틀라스로 정리했습니다. 원본 후보와 촬영용 코드는 배포 JAR 밖에 보관합니다.
