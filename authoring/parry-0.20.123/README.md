# 패리 연출 제작

참고 영상의 일반 패리 박자를 기준으로, 충돌한 월드·팔·무기 장면을 175ms 유지하고 짧은 확대·반동·미세 흔들림으로 이어지게 했습니다. 고정된 장면을 다시 그리는 동안 화면 변환은 장면 전체에 함께 적용합니다. HUD와 실제 게임 시간은 계속 진행합니다.

충돌점의 큰 별·작은 별·긴 방사선은 월드 좌표에 그립니다. 청록색과 금색을 번갈아 쓰고, 점선 끝과 계단 모양 폭으로 도트 형태를 유지합니다. 일반 패리에 특수 흑백 화면을 넣지 않습니다.

일반 무기는 두 개의 독립 가드를 선택합니다. 능사는 이미 검증한 어깨·손·손잡이 결합을 사용하되, 검날 축을 가장 짧은 회전으로 정면의 위쪽 대각선에 맞췄습니다. 가드가 유지되는 구간에서는 손목 회전이 고정됩니다. 팔의 뿌리는 어깨이고 팔·아이템 크기는 그대로입니다. 검은 막는 동안 완전히 뽑히며, 끝나면 기존 검집 복귀 흐름에 연결됩니다.

폰 6의 기존 패리·자동 패리·잔상 JSON은 변경하지 않았습니다. 원래 금속성 소리의 이벤트·음량·음높이도 그대로입니다. 일반 공격은 카메라 효과와 충돌 멈춤을 시작하지 않습니다.
