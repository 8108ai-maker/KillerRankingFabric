# 능사 독립 동작 0.20.99

`draw.json`, `sheathe.json`과 각 방향의 `ready_*`, `cut_*`, `align_*`는 별도 편집 가능한 Player Animator 동작입니다. Better Combat이 사용하는 세 베기 파일에는 이 동작들을 순서대로 합쳐 넣었습니다. 기존 공격 시간·서버 피해·로더·매핑은 유지합니다.

정규화된 26틱 중 2~5는 검집 축을 따라 23픽셀 뽑기, 5~7은 완전히 빠진 칼로 준비, 7~18은 각자의 베기, 18~20은 칼을 검집 앞쪽으로 가져오기, 20~22는 검집 밖에서 방향 맞추기, 22~24는 직선 삽입, 24~26은 원래 자세입니다. 손목 잡는 각은 세 동작 모두 고정하고, 팔 자체가 검을 운반합니다. 기존의 칼끝 속도에서 매 프레임 날 방향을 구하는 계산과 복귀 회전값을 강제로 2π 줄이는 처리는 사용하지 않습니다.

PAL의 회전 값은 출력 때 주기 각으로 정리됩니다. 시작/끝의 2π 차이는 실제로 같은 방향이므로 복귀 도중 그 차이를 풀면 불필요한 회전이 생깁니다. 동일한 손·칼 방향으로 연결하고, 검집에 들어가는 동안에는 회전시키지 않습니다. 팔과 무기 크기는 기본 크기를 유지합니다. 원거리 참격 제거와 0.20.98의 VFX는 그대로입니다.
