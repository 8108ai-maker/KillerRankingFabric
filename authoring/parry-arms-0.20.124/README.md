# 일반 패링 팔 모션 0.20.124

대상은 카타나 전용 모션을 제외한 일반 패링이다. 평타 모션은 변경하지 않았다.

참고 영상: https://www.youtube.com/watch?v=9NPbOl0LGds

- 맨손 패링 133.999990~135.483262초: 90장, 약 1/60초 간격.
- 무기 패링 18.999984~20.383262초: 84장, 약 1/60초 간격.
- 두 연속 구간의 진입·충돌·반동·복귀를 확인했다. 영상 전체 8분을 전부 프레임별로 확인했다는 뜻은 아니다.

최종 모션은 양손으로 공격을 옆으로 흘린다. 반대팔이 진입해 옆으로 유도하고 주손이 흘리는 경로를 이어받으며 양팔이 복귀한다. 중앙에서 버티는 정면 가드의 유지 구간은 없다. 반대편 클립은 맨손의 두 팔 역할도 뒤바꾼다. 일반 패링에서 반대팔을 숨기던 1인칭 설정을 해제했다. 떡발은 기존 팔 길이와 붕대 주먹 비율을 유지하는 별도 클립을 쓴다.

0~48의 49개 자세를 60fps 기준으로 작성했다. 유지 자세 대신 연속되는 측면 경로를 작성했고, 접선이 이어지는 보간으로 중간 자세마다 속도가 멈추는 현상을 줄였다. 일반 모션만 Player Animator의 재생 속도 3을 사용하며, 기존 카타나 패링에는 속도 조절기를 연결하지 않는다. 팔꿈치 관절이나 팔 확대는 추가하지 않았고, 손과 아이템이 같은 변환을 따른다.

0.20.123에서 추가했던 175ms 화면 멈춤과 큰 별·방사선은 제거했다. 충돌 효과는 0.20.122의 작은 효과로 복구했다. 기존 패링 성공 시점의 짧은 카메라 반응과 금속성 소리는 유지한다.

최종 실제 게임 촬영은 1920×1080, 30fps다. 패링 32회와 일반 공격 18개 보기의 자동 확인을 통과했다. 대표 막기·복귀 프레임을 육안으로 확인했으며, 원본 동작의 모든 수치나 오디오를 동일하게 복제했다고 주장하지 않는다.
